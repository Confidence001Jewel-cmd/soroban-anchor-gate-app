    Class EscrowGateClient

    Client for building Soroban invocations targeting the Anchor Gate escrow contract.

    The client is stateless and does not submit transactions. It validates inputs, encodes contract arguments with the Stellar SDK, and returns operations that callers can add to a TransactionBuilder, simulate, sign, and submit through their preferred RPC or wallet flow.

    Example

    const client = new EscrowGateClient({
      contractId: "CBIHLECKLMXYK6FPHSGGVYF6AHNFRHR3T5EIFIS3PFQDFKDQWNR25PHT",
      rpcUrl: "https://soroban-testnet.stellar.org",
      networkPassphrase: "Test SDF Network ; September 2015",
    });

    const operation = client.buildOperation(
      "get_escrow",
      client.buildGetEscrowTx(1n)
    );
