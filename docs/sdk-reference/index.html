    Soroban Anchor Gate Contract Client SDK - v0.1.0

    Type-safe client helpers for the Soroban Anchor Gate escrow contract.

    The module builds contract invocation arguments and operations, validates client configuration and user input, and parses contract results into ergonomic TypeScript values. It also re-exports the TTL inspector, SEP-38 quote helpers, and exact token unit conversion utilities that make up the public SDK surface.
